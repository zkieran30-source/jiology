## 论文简介

本文将机学定义为一个严格的四元模型：

```text
J = (S, M, I, C)
```

其中，`S` 表示系统状态，`M` 表示模块集合，`I` 表示交互机制，`C` 表示约束机制。状态更新函数、随机转移核或约束投影算子均属于由四元结构派生出的运行规则，不构成第五个基本对象。

论文在一个多主体资源分配仿真中检验该框架的最小形式。实验比较无显式约束、固定约束和自适应约束三种资源转移条件，并以最终 Gini 系数作为主要评价指标。实验结果仅适用于本文明确给出的仿真设定，不应被解释为机学能够解释所有复杂系统，或某种约束机制在所有现实场景中普遍更优。

## 运行实验

实验脚本使用 Python 3，并依赖 NumPy、Pandas 和 Matplotlib。运行：

```bash
python3 resource_sim.py
```

脚本将运行 40 个主体、200 个时间步和 200 个随机种子的仿真，并输出每种约束条件的汇总统计、95% 置信区间和资源不平等轨迹图。随机种子、模型参数和评价方式均在脚本中明确记录，以支持结果复现和后续审查。

## 研究边界

本材料是面向公开讨论的预印本和实验附件，不代表经过同行评审或已经被 arXiv 接收的正式期刊论文。当前实验是一个低维、同质主体的最小验证案例，尚未覆盖异质主体目标、学习行为、战略互动、动态网络拓扑、现实市场数据或组织数据。

后续工作包括与标准多主体资源分配基线进行比较，开展参数敏感性分析，加入异质主体和学习机制，公开完整实验日志，并在适当的数据集上检验模型的预测增益。
