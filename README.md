# 机学（Jiology）

**复杂动态系统的统一结构理论**

机学是一套以**状态（State）、模块（Module）、交互（Interaction）、约束（Constraint）**四元模型为核心的复杂动态系统统一结构理论。

## 核心表达

- 四元模型：**(S, M, I, C)**
- 状态演化方程：**s(t+1) = Π_C(s(t) + I(M_t))**
